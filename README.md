#  Rose Gold Banquet Hall Website

A responsive and modern banquet hall website designed to showcase wedding venues, event spaces, and banquet facilities with an elegant user experience.

## 🚀 Features

- 📱 Fully Responsive Design
- 🏛️ Multiple Banquet Hall Pages
- 💍 Wedding & Event Venue Showcase
- 🖼️ Interactive Image Galleries
- 🔍 SEO-Friendly Structure
- ⚡ Optimized Performance
- 🎨 Clean and Modern User Interface
- 📍 Easy Navigation and Accessibility

## 🛠️ Tech Stack

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 📦 Bootstrap

## 📸 Project Overview

This project was developed to provide visitors with a seamless browsing experience while exploring banquet halls and event venues. The website focuses on responsive design, performance optimization, and a professional visual presentation.
